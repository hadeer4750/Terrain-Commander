# Terrain Commander — Android 2.1

مساعد أوامر صوتية عربي للهاتف، مع إخراج الرد عبر مسار صوت الوسائط الذي يختاره Android (ومن ضمنه Bluetooth عند توصيل السيارة).

## الوظائف
- أوامر صوتية ونصية للملاحة، البيت ومكان العمل، الوقود والمطاعم القريبة.
- إرسال طلب Android MEDIA_PLAY_FROM_SEARCH إلى YouTube Music أو Spotify أو مشغّل يختاره المستخدم. يعتمد التشغيل على دعم التطبيق وحسابه؛ فتح النشاط لا يثبت بدء التشغيل. عند غياب الدعم يظهر اختيار مشغّل آخر أو بحث يدوي.
- فتح لوحة الاتصال لرقم هاتف أو فتح محادثة WhatsApp؛ الإرسال والاتصال يؤكدهما المستخدم في التطبيق المعني.
- الوقت، حفظ عنوان البيت والعمل واللغة وتفضيلات الصوت على الهاتف.
- إعادة الاستماع بعد الرد أثناء فتح التطبيق. يتوقف عند الانتقال لتطبيق آخر أو إغلاق الشاشة، ويمكن بدء جلسة جديدة بالزر.

## التثبيت
من GitHub Actions افتح آخر بناء ناجح ثم نزّل Terrain-Commander-APK وفك ZIP وثبّت Terrain-Commander-2.1.apk. يتطلب Android 8 أو أحدث. هذه نسخة debug موقعة للتجربة وليست إصدار متجر.

اسمح بالميكروفون عند الطلب. يلزم محرك تعرف صوتي ومحرك نطق يدعمان العربية؛ قد يستخدم محرك التعرف اتصال الإنترنت. اربط الهاتف بالسيارة واختر Bluetooth Audio لسماع الرد. استخدام ميكروفون السيارة يعتمد على Android ووحدة السيارة؛ التطبيق لا يفرض مسار ميكروفون Bluetooth ولا يضمنه.

## حدود هذه النسخة
هذه أوامر محددة وليست محادثة AI عامة. لا يوجد تنبيه بكلمة أو تشغيل دائم في الخلفية، ولا تحكم بوظائف السيارة الداخلية أو عرض على شاشة Android Auto. أمر «ابحث عن أغنية» يفتح البحث اليدوي، وأمر «شغل أغنية» يرسل طلب تشغيل.

## البناء
JDK 17، Gradle 8.10.2، Android Gradle Plugin 8.7.3، SDK 35.

```sh
gradle :app:assembleDebug :app:lintDebug
```

يفحص GitHub Actions البناء وAndroid Lint وتوقيع APK وهوية الحزمة. يلزم اختبار الصوت والبلوتوث فعليًا على الهاتف والسيارة.

## تغييرات 2.1
حفظ مكان العمل من الإعدادات أو «احفظ مكان عملي في ...»، والملاحة باستخدام «وصلني للعمل» أو «وديني للدوام».

نسخة 2.0 استعملت مفتاح debug مؤقتًا غير محفوظ. قد يتطلب تثبيت 2.1 حذف 2.0 أولاً، وهذا يمسح إعداداتها؛ انسخ عنوان البيت قبل الحذف. تُخزن نسخة اختبار المفتاح في cache للبناء اللاحق، وليست آلية توقيع إصدار إنتاجي.
