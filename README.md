# Terrain Commander — Android 2.4

مساعد أوامر صوتية عربي للهاتف، مع إخراج الرد عبر مسار صوت الوسائط الذي يختاره Android (ومن ضمنه Bluetooth عند توصيل السيارة).

## الوظائف
- أوامر صوتية ونصية للملاحة، البيت ومكان العمل، الوقود والمطاعم القريبة.
- إرسال طلب Android MEDIA_PLAY_FROM_SEARCH إلى YouTube Music أو Spotify أو مشغّل يختاره المستخدم. يعتمد التشغيل على دعم التطبيق وحسابه؛ فتح النشاط لا يثبت بدء التشغيل. عند غياب الدعم يظهر اختيار مشغّل آخر أو بحث يدوي.
- فتح لوحة الاتصال لرقم هاتف أو فتح محادثة WhatsApp؛ الإرسال والاتصال يؤكدهما المستخدم في التطبيق المعني.
- الوقت، حفظ عنوان البيت والعمل واللغة وتفضيلات الصوت على الهاتف.
- إعادة الاستماع بعد الرد أثناء فتح التطبيق. يتوقف عند الانتقال لتطبيق آخر أو إغلاق الشاشة، ويمكن بدء جلسة جديدة بالزر.

## التثبيت
من GitHub Actions افتح آخر بناء ناجح ثم نزّل Terrain-Commander-APK وفك ZIP وثبّت Terrain-Commander-2.4.apk. يتطلب Android 8 أو أحدث. هذه نسخة debug موقعة للتجربة وليست إصدار متجر.

اسمح بالميكروفون عند الطلب. يلزم محرك تعرف صوتي ومحرك نطق يدعمان العربية؛ قد يستخدم محرك التعرف اتصال الإنترنت. اربط الهاتف بالسيارة واختر Bluetooth Audio لسماع الرد. استخدام ميكروفون السيارة يعتمد على Android ووحدة السيارة؛ التطبيق لا يفرض مسار ميكروفون Bluetooth ولا يضمنه.

## حدود هذه النسخة
هذه أوامر محددة وليست محادثة AI عامة. لا يوجد تنبيه بكلمة أو تشغيل دائم في الخلفية، ولا تحكم بوظائف السيارة الداخلية أو عرض على شاشة Android Auto. أمر «ابحث عن أغنية» يفتح البحث اليدوي، وأمر «شغل أغنية» يرسل طلب تشغيل.

## البناء
JDK 17، Gradle 8.10.2، Android Gradle Plugin 8.7.3، SDK 35.

```sh
gradle :app:assembleDebug :app:lintDebug
```

يفحص GitHub Actions البناء وAndroid Lint وتوقيع APK وهوية الحزمة. يلزم اختبار الصوت والبلوتوث فعليًا على الهاتف والسيارة.

## تغييرات 2.1
حفظ مكان العمل من الإعدادات أو «احفظ مكان عملي في ...»، والملاحة باستخدام «وصلني للعمل» أو «وديني للدوام».

نسخة 2.0 استعملت مفتاح debug مؤقتًا غير محفوظ. قد يتطلب تثبيت 2.1 حذف 2.0 أولاً، وهذا يمسح إعداداتها؛ انسخ عنوان البيت قبل الحذف. تُخزن نسخة اختبار المفتاح في cache للبناء اللاحق، وليست آلية توقيع إصدار إنتاجي.

## تغييرات 2.2
إضافة YouTube العادي كخيار منفصل، وحفظه دون تحويله إلى YouTube Music عند إعادة الفتح. يرسل التشغيل إلى حزمة YouTube ويستخدم بحث YouTube في المسار اليدوي. لا يمكن ضمان تشغيل الفيديو تلقائيًا؛ قد يلزم الضغط على تشغيل داخل YouTube.

## ملفات الهاتف — 2.3
- من «أغاني الهاتف» اختر مجلدًا محليًا يحتوي ملفاتك، ثم امنح قراءة المجلد. لا توجد صلاحية عامة لكل ملفات الهاتف. تُحفظ الفهرسة محليًا، حتى 5000 ملف في المجلد والمجلدات الفرعية (عمق 12).
- البحث بالاسم يعتمد على اسم الملف (مع تسوية بعض اختلافات الحروف العربية). إن تطابقت عدة أغنيات يظهر اختيار بدل تشغيل أغنية عشوائية. ملفات خدمات البث المحمية لا يمكن قراءتها كأغانٍ عادية.
- «مشغّل الهاتف الافتراضي» يفتح الملف نفسه عبر Android ACTION_VIEW مع صلاحية قراءة مؤقتة. يحدد Android المشغّل الافتراضي أو يعرض اختيارًا؛ التشغيل بعد الفتح يبقى تحت تحكم ذلك التطبيق.
- «داخل Terrain Commander» يشغّل الملف باستخدام MediaPlayer وخدمة foreground مع MediaSession وإشعار. يستمر مع إطفاء الشاشة ويدعم التالي والسابق والإيقاف المؤقت والاستكمال. ينهي زر «إنهاء» الخدمة. ينقطع الصوت عند فقدان التركيز الصوتي أو فصل مخرج الصوت.
- يوقف بدء الاستماع الموسيقى الداخلية مؤقتًا. تشغيل الموسيقى يوقف جلسة الاستماع لمنع تفسير الأغنية كأوامر؛ اضغط الميكروفون لإعطاء أمر جديد. الأوامر: «شغل [اسم الملف]»، «وقف الموسيقى»، «كمل»، «التالي»، «السابق».
- الصوت المحلي لا يحتاج إنترنت؛ خدمة التعرف الصوتي قد تحتاجه. دعم صيغة الملف يعتمد على Android.
- التحقق: اختبارات أوامر JavaScript، مطابقة الأسماء على JVM، واختبار تشغيل ملف WAV وإيقافه واستكماله والتالي والاستمرار مع مغادرة الواجهة والتعامل مع ملف مفقود على محاكي Android 13. يبقى اختبار Bluetooth والمشغّل الافتراضي ومنتقي مجلد الهاتف الفعلي مطلوبًا على الجهاز.

## إصلاح 2.4
إصلاح «تشغيل موسيقى» و«شغل الموسيقى» وصيغ الطلب العربية، واعتماد المشغّل الظاهر في القائمة وقت التنفيذ. لم تعد الأوامر غير المفهومة تُفتح تلقائيًا في بحث ويب؛ يتطلب بحث الويب طلبًا صريحًا. أيقونة GMC حمراء بخلفية داكنة؛ التطبيق غير تابع لشركة GMC.
